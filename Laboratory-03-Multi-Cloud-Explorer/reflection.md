# Mission Reflection

After completing the Cloud Computing mission, the cloud platform that impressed me the most was **Amazon Web Services (AWS)**. I liked AWS because it offers many different cloud services that can be used for computing, storage, databases, networking, and other IT needs. I also found it useful that AWS can support different types of organizations, from startups to large businesses.

AWS, Azure, and GCP have many similarities because they all provide cloud computing services that allow users and businesses to access IT resources over the internet. They all offer services for virtual machines, storage, databases, networking, and identity management. They also provide global infrastructure and allow users to increase or decrease resources depending on their needs. Even though they have similar services, each platform has its own features and strengths.

Business requirements have an important role in selecting a cloud platform. A company should consider its budget, existing technologies, type of applications, number of users, security needs, and expected growth. For example, Azure can be a good choice for an organization that already uses Microsoft products, while Google Cloud can be suitable for AI and machine learning projects. AWS can be useful for businesses that need a wide range of cloud services.

Acting as a Cloud Solutions Consultant helped me understand that choosing a cloud platform is not simply about picking the most popular one. I had to look at the specific situation of each client and match their requirements with the services offered by each platform. This helped me practice analyzing problems and making technical recommendations.

Lastly, my GitHub Cloud Computing Portfolio improved because I was able to organize my research, comparisons, recommendations, and Linux investigation into different files. I also added screenshots and documentation of the activities I completed. Because of this mission, my portfolio became more complete and showed not only what I learned about cloud computing but also how I applied that knowledge to different scenarios.
