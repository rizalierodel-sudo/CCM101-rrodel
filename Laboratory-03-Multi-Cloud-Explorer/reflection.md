# Reflection

After completing the Cloud Computing laboratory activities, I learned more about how cloud computing is used in different situations. Before doing these activities, I mostly knew cloud computing as a way of storing files or using online services. However, I learned that cloud platforms can also be used to run applications, manage databases, store data, and provide virtual servers for businesses and organizations.

One of the activities that I found helpful was comparing AWS, Microsoft Azure, and Google Cloud Platform. I learned that the three platforms offer similar services, but they also have different strengths. AWS has a wide range of services, Azure works well with Microsoft technologies, and Google Cloud is known for AI, data analytics, and Kubernetes. This helped me understand that choosing a cloud platform should depend on the needs and requirements of an organization.

The Linux investigation was also useful because I was able to work with a server through the terminal. I used commands such as `cat /etc/os-release`, `lscpu`, `free -h`, and `df -h` to check the operating system, CPU, memory, and disk space. I learned that these details are important when deciding what type of cloud virtual machine can be used for a server.

Overall, these activities gave me a better understanding of cloud computing and its practical uses. I also realized that learning cloud computing is not only about knowing the names of different services. It is also about understanding what each service can do and choosing the right one based on a specific situation. As an IT student, I think these activities will be useful as I continue learning about servers, cloud technologies, and other IT systems.
