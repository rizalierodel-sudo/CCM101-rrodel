# Laboratory 05 - Cloud Data Engineer

## Mission Overview

In this laboratory activity, I deployed an S3-compatible object storage server using MinIO and Docker. I accessed the MinIO Web Console, created a storage bucket, and uploaded a sample file to test the object storage system.

## Objectives

- Differentiate between Block, File, and Object Storage.
- Deploy an S3-compatible Object Storage server using MinIO and Docker.
- Access a cloud service through a web interface using port forwarding.
- Create a storage bucket and upload an object.
- Document cloud storage operations using Markdown.

## Tools Used

- KillerCoda Ubuntu Playground
- Docker
- MinIO
- GitHub
- Web Browser

## Skills Learned

- Deploying a cloud storage server using Docker
- Using MinIO for object storage
- Creating and managing storage buckets
- Uploading objects to cloud storage
- Using port forwarding to access a web console
- Documenting cloud computing activities using Markdown
