# Reflection

After completing the Cloud Computing laboratory activities, I learned more about how cloud computing is used in different situations. Before doing these activities, I mostly knew cloud computing as a way of storing files or using online services. However, I learned that cloud platforms can also be used to run applications, manage databases, store data, and provide virtual servers for businesses and organizations. The activities helped me understand that cloud computing is not only about accessing files online, but it can also provide many resources that are normally needed to build and operate an IT system.

One of the activities that I found helpful was comparing AWS, Microsoft Azure, and Google Cloud Platform. I learned that the three platforms offer similar services, but they also have different strengths. AWS has a wide range of services, Azure works well with Microsoft technologies, and Google Cloud is known for AI, data analytics, and Kubernetes. This helped me understand that choosing a cloud platform should depend on the needs and requirements of an organization. I also learned that there is no single cloud platform that is always the best choice for every company. The right platform depends on the type of application, available resources, budget, and other requirements.

The different client scenarios also helped me understand how cloud platforms can be selected based on specific needs. For example, Azure can be a good choice for a company that already uses Microsoft products, while Google Cloud can be suitable for organizations working with AI and machine learning. AWS can also be useful for businesses that need many different cloud services and flexible resources. This activity made the comparison more realistic because I had to think about the situation of each client instead of simply choosing a platform based on its popularity.

The Linux investigation was also useful because I was able to work with a server through the terminal. I used commands such as `cat /etc/os-release`, `lscpu`, `free -h`, and `df -h` to check the operating system, CPU, memory, and disk space. I learned that these details are important when deciding what type of cloud virtual machine can be used for a server. It also gave me a better understanding of how system resources can be checked even without using a graphical interface.

Overall, these activities gave me a better understanding of cloud computing and its practical uses. I also realized that learning cloud computing is not only about knowing the names of different services. It is also about understanding what each service can do and choosing the right one based on a specific situation. The activities also helped me practice researching, comparing information, and making simple technical decisions. As an IT student, I think these activities will be useful as I continue learning about servers, cloud technologies, and other IT systems. I also feel that having basic knowledge of cloud platforms will be helpful in the future because many organizations now use cloud-based technologies for their daily operations.
