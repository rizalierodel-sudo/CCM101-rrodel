# Security Audit Report

## 1. Principle of Least Privilege (PoLP)

The Principle of Least Privilege means giving users only the permissions they need to do their tasks. It is important for cloud user accounts because it helps prevent unauthorized access and reduces the risk of security problems.

## 2. Attack Surface

The attack surface refers to all the possible points where an attacker can try to access a virtual machine. These may include open network ports, running services, and applications that are exposed to possible attacks.

## 3. Default Deny Policy

A Default Deny Policy means blocking all incoming traffic unless it is specifically allowed. It is safer because it limits access to necessary services instead of trying to identify and block every possible hacker individually.
