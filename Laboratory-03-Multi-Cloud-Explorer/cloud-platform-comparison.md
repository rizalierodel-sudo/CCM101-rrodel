## Questions and Answers

### 1. Which cloud provider offers the broadest range of services?

AWS offers one of the broadest ranges of cloud services among the three major providers. It provides many options for computing, storage, databases, networking, security, and other cloud needs.

### 2. Which provider best integrates with Microsoft technologies?

Microsoft Azure best integrates with Microsoft technologies because it is developed by Microsoft. It works well with products and technologies such as Windows Server, Microsoft 365, and other Microsoft services.

### 3. Which provider is strongest in Artificial Intelligence and Kubernetes?

Google Cloud is known for its strong capabilities in Artificial Intelligence, data analytics, and Kubernetes. It is a good choice for organizations that focus on AI applications and containerized workloads.

### 4. Which cloud platform would you personally choose and why?

I would personally choose AWS because it offers many different services that can be useful for different types of projects. As an Information Technology student, I also think it would be useful to learn because of the wide range of tools and services available.
