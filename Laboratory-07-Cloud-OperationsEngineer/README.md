# Laboratory 07 – Cloud Operations Engineer

## Mission Overview

This laboratory focuses on basic cloud operations tasks, including system monitoring, container deployment, application testing, log analysis, and resource monitoring. These activities help develop skills in checking system health and identifying possible application issues.

## Objectives

- Monitor system memory and disk usage.
- Deploy an Nginx web server using Docker.
- Test website accessibility using `curl`.
- Inspect application logs and identify errors.
- Monitor container CPU, memory, and network usage.

## Tools Used

- KillerCoda Ubuntu Playground
- Docker
- Nginx
- Linux commands
- `curl`
- `docker logs`
- `docker stats`
- GitHub

## Activities Completed

1. Checked system memory, disk space, and system activity.
2. Deployed an Nginx container named `clientwebsite`.
3. Tested the website using `curl` and checked a page that returned a 404 error.
4. Reviewed container logs to identify successful requests and errors.
5. Monitored the container's CPU, memory, and network usage using `docker stats`.

## Screenshots

The `screenshots/` folder contains the screenshots collected during the laboratory activities, including system monitoring, Nginx deployment, website testing, log analysis, and container metrics.

## Skills Learned

Through this laboratory, I learned how to monitor system resources, deploy a web server using Docker, test application responses, analyze container logs, and check resource usage. I also learned how these tasks help cloud operations engineers monitor applications and troubleshoot basic issues.
