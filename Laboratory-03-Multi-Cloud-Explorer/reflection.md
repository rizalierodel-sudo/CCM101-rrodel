# Reflection

After completing the Cloud Computing laboratory activities, I learned more about how cloud computing platforms work and how they can be used in different situations. I was able to explore AWS, Microsoft Azure, and Google Cloud Platform and compare their services, strengths, and possible uses for different organizations.

One thing I learned from the activities is that AWS, Azure, and GCP have similar services, but each platform has its own strengths. I also learned that choosing a cloud platform depends on the needs of a company or organization. For example, Azure can be a good choice for organizations that already use Microsoft technologies, while Google Cloud can be useful for AI and data-related projects. AWS also provides many different services that can support various types of applications.

The Linux investigation also helped me understand how cloud servers work. By using commands such as `lscpu`, `free -h`, and `df -h`, I was able to check the CPU, memory, and disk space of a Linux server through the terminal. I also learned that the information about the server's resources can be useful when choosing a suitable cloud virtual machine.

Overall, this activity helped me understand cloud computing in a more practical way. Instead of only reading about cloud services, I was able to compare actual platforms and work with Linux commands. I also learned that cloud computing can provide flexible resources and can be useful when an organization needs to move its systems to the cloud. This activity gave me a better idea of how cloud technologies are used in real-world IT environments.
