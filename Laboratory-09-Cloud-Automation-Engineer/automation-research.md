# Automation Research

## 1. Bash Script

A Bash script is a file that contains Linux commands that run in order to perform tasks automatically. The `#!/bin/bash` line is called a shebang. It tells the system to use Bash to execute the script.

## 2. Variables

Variables store values that can be reused in a script. For example, `$BACKUP_DIR` stores the location of the backup folder, so we do not need to type the same path repeatedly. This makes the script easier to manage and update.

## 3. Cron Job

A Cron Job is a scheduled task in Linux that runs a command or script at a specific time. It is important in cloud operations because it automates repetitive tasks, such as creating backups, without requiring someone to run them manually every time.
