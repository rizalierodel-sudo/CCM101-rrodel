# Microsoft Azure Research

## Brief Overview

Microsoft Azure is a cloud computing platform developed by Microsoft. It provides different cloud services that people and businesses can use to run applications, store data, manage databases, and handle other IT resources online.

## Global Infrastructure

Azure has a global infrastructure with Regions and data centers located in different parts of the world. These locations allow Azure to provide its services to users from different areas. Having different regions also helps businesses improve the availability and performance of their applications.

## Cloud Management Console

The Azure Portal is the web-based management console used to access and manage Azure services. Users can use the portal to create resources, check their services, manage settings, and monitor their cloud resources in one place.

Official Website: https://azure.microsoft.com/

## Four (4) Core Services

1. **Azure Virtual Machines** – Provides virtual computers that can be used to run applications and operating systems.
2. **Azure Blob Storage** – A storage service used for storing files, images, videos, backups, and other types of data.
3. **Azure SQL Database** – A managed database service that can be used to store and manage application data.
4. **Azure Functions** – Allows users to run small pieces of code without having to manage servers.

## Three (3) Advantages

1. **Scalability** – Azure resources can be increased or reduced depending on the needs of a business.
2. **Microsoft Integration** – Azure works well with other Microsoft products and technologies.
3. **Global Availability** – Azure has infrastructure in different parts of the world, making its services accessible to users in many locations.

## Typical Enterprise Use Cases

Businesses use Azure for hosting websites and applications, storing data, managing databases, developing software, and supporting their IT infrastructure. It can also be used for backup, data analytics, and other business operations.
