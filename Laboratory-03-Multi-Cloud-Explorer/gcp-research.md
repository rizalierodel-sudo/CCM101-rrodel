# Google Cloud Platform (GCP) Research

## Brief Overview

Google Cloud Platform (GCP) is a cloud computing platform provided by Google. It offers different cloud services that can be used for storing data, running applications, managing databases, analyzing information, and developing software.

## Global Infrastructure

Google Cloud has a global infrastructure made up of Regions and Zones in different parts of the world. Regions are geographic locations where Google Cloud services are available, while Zones are separate locations within a Region. This setup helps businesses run their applications with better availability and performance.

## Cloud Management Console

The Google Cloud Console is the web-based management console used to access and manage Google Cloud services. Users can use it to create resources, manage projects, check services, and monitor their cloud resources from one place.

Official Website: https://cloud.google.com/

## Four (4) Core Services

1. **Compute Engine** – Provides virtual machines that can be used to run applications and other workloads.
2. **Cloud Storage** – A storage service used for files, backups, images, videos, and other data.
3. **BigQuery** – A service used to store and analyze large amounts of data.
4. **Cloud Run** – Allows users to run and deploy applications without having to manage the servers directly.

## Three (3) Advantages

1. **Scalability** – Google Cloud resources can be adjusted depending on the needs of a business.
2. **Data Analytics** – It provides tools that can help businesses process and analyze large amounts of data.
3. **Global Infrastructure** – Its infrastructure is available in different locations around the world, helping businesses provide reliable services to their users.

## Typical Enterprise Use Cases

Businesses use Google Cloud for hosting websites and applications, storing data, analyzing information, developing software, and deploying cloud-based applications. It can also be used for artificial intelligence, machine learning, and other data-related tasks.
